# Sistema de Gestión de Biblioteca
Examen de Fundamentos de la Programación desarrollado en C#.

## Funcionalidades
- Registrar libros.
- Consultar catálogo.
- Buscar libros por título o autor.
- Registrar préstamos y devoluciones.
- Mostrar libros disponibles y prestados.
- Guardar información en archivos de texto.
